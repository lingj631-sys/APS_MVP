# APS 规则方案编辑器操作手册

> 适用页面：`/rule-sets`（主界面右上角「规则集」入口）
> 适用对象：计划、物流、生产、工艺等业务同事
> 版本：2026-11 可视化编辑器版
> 一句话：在这里用中文告诉系统“排产要遵守什么”，先试算，再保存和启用。

---

## 0. 本版变化（2026-11）

- 页面从“表格 + 参数 JSON”改为 **左侧规则清单 + 右侧业务详情**，日常配置不再需要写 JSON。
- 规则卡片右上角显示“必须/尽量、成品/半成品、产线/料号、已修改”等标签。
- 新增 **保存当前版本**（草稿/使用中版本原地覆盖）和 **版本管理与说明**（补写版本说明、删除历史版本）。
- 新增 **试算此方案**：可选择计划期（7/10/15/30 天）、工作制（7×3/6×3/5×3/5×2/4×3）和每班工时（8/12 小时）。
- 页面按浏览器宽度自适应，80% 缩放下仍保持左右布局。

---

## 1. 这个页面解决什么问题

排产结果不理想时，通常不是算法坏了，而是“规则”需要调整。例如：

- 半成品被拆成 1 件、2 件的碎班次；
- 某条产线负荷长期达不到 95%；
- 战略客户没有优先保供；
- 换型太频繁，想把同模具的工单排在一起。

以前改这些规则要改英文参数或 JSON，业务同事很难独立完成。新编辑器把它们翻译成了业务语言：

- **按业务主题分组**：现场必须遵守、交付与客户、产能与班次、换型与合并、库存；
- **用开关、下拉、数字填写**：不需要写 JSON；
- **先试算再启用**：改完先看结果，满意后再保存/设为当前方案；
- **版本化**：每次调整都有记录，可以回看、回滚、写版本说明。

## 2. 先认识三个数字：27 / 17 / 13

页面上经常同时出现三个数字，它们不是同一层东西：

| 数字 | 含义 | 用业务话说 |
|---:|---|---|
| **27** | 业务规则目录条数（WL；SY38 是 9） | 我们和业务确认过的“规则清单”，包含约束、校验、测试场景等 |
| **17** | 排产后的检查项数量 | 排完计划后的“体检表”，17 项全过代表计划通过校验 |
| **13** | 当前方案里的可调规则条数 | 这个页面里真正能改的规则；成品/半成品拆开后是 13 条 |

它们不是一一对应关系：

- 27 条业务规则里，有些只用于校验或展示，不是求解约束；
- 13 条可调规则是把 27 条中的求解约束落到 20 个固定模板上，并把产能、批量按成品/半成品拆开；
- 27 页显示的“权重 8000% / 2500%”是旧业务权重，和这里的“重要程度”不是同一套标尺，不能直接互抄。

> 当前示例方案 v6 是 11 条“必须满足” + 2 条“尽量满足” = 13 条。以页面顶部显示的当前版本为准。

### 3.1 顶部操作栏

| 控件 | 用途 | 什么时候用 |
|---|---|---|
| 工厂 | 温岭 WE34 / 沈阳 SY38 | 两个工厂各自有独立的规则方案 |
| 版本 | 当前工厂的历史版本列表 | 回看、对比、回滚 |
| 状态 | 使用中 / 草稿 / 历史版本 | 确认当前看的是哪一版 |
| 试算此方案 | 用当前草稿跑一次排产，看指标 | 改完规则、保存前 |
| 保存当前版本 | 直接覆盖当前版本 | 草稿微调，或确认要立即修改生效方案 |
| 另存为新版本 | 生成 v+1，保留原版本 | 正式调整、需要回滚时 |
| 设为当前方案 | 让某个版本成为“使用中” | 新版本试算满意后 |
| 更多 | 添加规则、版本管理、Excel、冲突检查、敏感度 | 进阶操作 |

### 3.2 摘要条与版本说明

- **必须满足 / 尽量满足 / 已停用**：当前方案里各类规则的条数。
- **已保存 / 有未保存修改**：提示当前修改是否已经落库。
- **试算口径**：显示上次选择的计划期、工作制和每班工时；点它可以直接打开试算。
- **版本说明**：用一句话写清“这版改了什么、为什么改”，例如：
  - `v6：半成品每班至少 100 件，消除 1~2 件碎班次`
  - `v7：只把成品上限调到 105%，半成品保持 100%`
  - 点“编辑”可以随时补充或修改。

## 4. 规则卡片怎么读

左侧每张卡片包含：

- **规则名称**：白话标题，例如“最少投产批量”“班次负荷区间”。
- **一句话说明**：当前设置的效果，例如“每班至少 100 件”“95% ~ 100% · 尾班豁免”。
- **右上角标签**：
  - `必须`：做不到就不允许排出计划；
  - `尽量`：做不到会扣分，但不会拒绝排产；
  - `成品 / 半成品`：规则只作用于这个阶段；
  - `产线 xxx`、`料号 xxx`：规则只作用于指定范围；
  - `已修改`：与已保存版本相比有变化。

**例子**：

```
最少投产批量
每班至少 100 件
[必须] [半成品]
```

表示：这是一条必须满足的规则，只作用于半成品；半成品每个开班至少投产 100 件。

停用的规则卡片会变灰，但仍保留在方案里；重新打开开关即可恢复。

## 5. 改一条规则的完整步骤

以“半成品不再出现 1~2 件碎班次”为例：

1. 左侧打开 **03 产能与班次**，找到 **最少投产批量**（半成品）。
2. 在右侧“具体设置”里确认：
   - 按什么计量：**按件**
   - 约束范围：**每个班次**
   - 每班最少投产件数：**100**
3. 违反后果选择 **必须满足**。
4. 点右上角 **试算此方案**，选择 `10 天 · 7×3 · 8h`。
5. 看试算结果里的 **半成品小于 MPQ 的班次** 是否降到 0，同时看准时交付率和低于 95% 的班次。
6. 满意后选择：
   - **保存当前版本**：直接覆盖当前版本（草稿或使用中版本）；
   - **另存为新版本**：生成新版本，保留旧版本可回滚。
7. 如果保存的是新版本，点 **设为当前方案** 才会生效。
8. 回到主界面重新排产。

> 注意：只改参数、不保存，不会影响任何排产；保存但未“设为当前方案”的新版本也不会生效。

## 6. 五类规则说明

> 说明：下面按业务主题归类，左侧页面里的实际分组可能因方案不同而略有差异；部分规则可以通过“高级设置 → 分组”移动。表中标注“预留”的字段当前不会改变排产结果，页面保留是为了后续接入；判断一条规则是否真的生效，以“试算此方案”的结果为准。

### 6.1 01 现场必须遵守

这一组是“物理上做不到就不能排”的规则，通常保持“必须满足”。

| 规则 | 用途 | 关键设置 | 例子 / 注意 |
|---|---|---|---|
| 模具 / 工装独占 | 同一套模具在同一时间只能给一条线用 | 模具/工装、可用套数 | 只有 1 套模具时，两条线不能同班同时用 |
| 前后工序齐套 | 后道开工前，前道半成品要留缓冲 | 间隔班次、是否计入库存 | 半成品上一班产出、下一班可用，间隔填 0 |
| 物料到货门控 | 关键物料未到货前不允许开工 | 到货依据、检验放行小时 | 物料 10/14 到货，10/14 之前的班次不能排 |
| 设备维保避让 | 设备保养期间不排产 | 维保期间怎么做、可用产能 | PM 计划 8 小时，产线在这 8 小时不排 |
| 同料号顺位生产 | 同一料号按交期先后生产，避免插队 | 排序依据（允许跳序班次为预留） | 先到期的订单先排，后到期的不能插到前面 |
| 最少投产批量 | 限制单班或整单的最小投产数量 | 按整箱/按件、每班/整单、最少件数 | 半成品每班至少 100 件，避免 1~2 件碎班次 |
| 受控时间窗 | 只允许在指定日期/班次生产 | 允许班次、允许日期 | 试产件只允许 11/05 早班和中班生产 |
| 联产品同步产出 | 左右件/共模产品按比例同步产出 | 产出比例、联产品组 | L/R 按 1:1 同步产出 |
| 替代产线 | 允许任务在替代产线上生产 | 最多候选线、选线方式 | **当前求解器尚未接入，添加后不会改变结果** |

**最少投产批量的两个常见写法**：

- 半成品避免碎班次：`按件 + 每个班次 + 最少 100 件`；
- 成品按整箱：`按整箱（MPQ） + 每个班次`，每个开班必须是整箱的倍数。

> 如果希望“整张工单至少达到一个包装量”，把“约束范围”改成“整张工单”；这时只看整单总量，不要求每班都达到 100 件。

### 6.2 02 交付与客户

| 规则 | 用途 | 关键设置 | 例子 / 注意 |
|---|---|---|---|
| 交期 / 截单 | 规定订单必须准时，或把延误作为惩罚 | 必须准时/尽量准时（截单时刻、允许延误为预留） | 必须准时：晚于交期就无解；尽量准时：允许晚，但会扣分 |
| 客户分级保供 | 战略客户优先保供 | 三类客户的重要程度（交期窗口为预留） | 战略 10、核心 3、普通 1；战略客户晚交的罚分更高 |

> 客户分级只在“尽量准时”时明显起作用；如果交期是“必须准时”，系统首先保证不晚于交期。

### 6.3 03 产能与班次

| 规则 | 用途 | 关键设置 | 例子 / 注意 |
|---|---|---|---|
| 班次负荷区间 | 规定每个已开班次的负荷下限/上限 | 最低负荷、最高负荷、尾班豁免 | 成品 95%~105%；半成品 95%~100% |
| 最少投产批量 | 见 6.1 | 按整箱/按件、每班/整单 | 半成品每班至少 100 件 |
| 工作日历 | 一周上几天、每天几个班 | 7×3 / 6×3 / 5×3 / 5×2 / 4×3 | 做五休二、每天 3 班 |
| 人力上限 | 按在岗人数限制开班/产出 | 可用人数、换模技术员（加班/人员来源为预留） | 某班只有 6 人，不能同时开两条满员线 |

**关于 95% 和 105%**：

- `95%` 是**已开班次的最低负荷**；没开班的班次不算；
- `100%` 是正常上限；`105%` 是允许的加班上浮；
- “尾班豁免”只对每条线当天的最后一个开班生效；
- 半成品如果既要“MPQ 整块”又要“硬 95%”，在 100% 上限下可能无解，需要选择：
  - 允许半成品 105% 上浮；
  - 或使用“每班至少 100 件”而不是严格整倍；
  - 或把 95% 改成“尽量满足”。

### 6.4 04 换型与合并

| 规则 | 用途 | 关键设置 | 例子 / 注意 |
|---|---|---|---|
| 换型时间 | 每次换型/换模的耗时 | 按开工次数/型号切换（换型分钟为预留，实际换型以 Setup-Matrix/TRP 为准） | 换模一次 45 分钟 |
| 单班型号数量 | 一个班次最多同时生产几个型号 | 最多型号数、按班/按天 | 一个班最多 3 个型号，减少频繁换型 |
| 连续生产（块数上限） | 限制一张工单最多拆成几块 | 最多块数 | 一张工单最多拆 2 块；设“必须”可能无解，建议先“尽量” |
| 同模连产 | 同模具工单连续生产 | 最多块数、交期是否可让行 | 模具 M01 尽量连续排 |

### 6.5 05 库存

| 规则 | 用途 | 关键设置 | 例子 / 注意 |
|---|---|---|---|
| 库存上下限 | 控制库存覆盖天数，避免断料或爆仓 | 最多库存天数（最少天数/安全库存为预留） | 成品最多提前 5 天生产；安全库存 100 件 |

> 当前库存规则是“不要过早生产”的近似；更完整的库存上下限模型还在后续建设中。

## 7. 高级设置

高级设置默认折叠，点开后才显示。日常调整通常不需要动。

### 7.1 适用产线 / 阶段 / 料号

- **适用产线**：只对某条线生效，例如 `PGLINKAGE`；留空 = 全部产线。
- **适用阶段**：成品 / 半成品 / 全部。
- **适用料号**：只对某个料号生效，例如 `WA14208`；留空 = 全部料号。

**例子**：只让 PGLINKAGE 的成品允许 105%：

1. 新增一条“班次负荷区间”规则；
2. 适用范围选 `成品`，产线填 `PGLINKAGE`；
3. 最高负荷填 `105%`；
4. 其他产线仍走原来的规则。

### 7.2 分组、组内顺序、继承

- **分组**：把规则放到“现场必须遵守 / 交付与客户 / 产能与班次 / 换型与合并 / 库存”之一。
- **组内顺序**：数字越小越优先；一般保持 0 即可。
- **继承方式**：
  - `覆盖同组低优先级规则`：更具体的规则替换宽规则；
  - `与同组规则叠加`：两条规则同时生效。

### 7.3 重要程度（权重）

- 只在“尽量满足”时有意义；“必须满足”的规则忽略重要程度。
- 用“低 / 中 / 高”三个快捷按钮即可，底层是 0~1000 的相对值。
- **重要程度是组内相对值**，不是分钟/金额，也不能和 27 页的旧权重直接比较。
- 如果一组只有一条“尽量满足”规则，改重要程度通常不会改变结果。

### 7.4 生效 / 失效日期

- 留空 = 立即生效、长期有效；
- 适合临时试产、短期保供策略；
- 到期后规则自动不再生效（需要保存并设为当前方案）。

### 7.5 技术信息

“技术信息（只读）”里是规则 ID、模板 ID 和原始参数，给技术同事排查用。业务同事不需要修改，也不要在日常操作中依赖它。

### 7.6 删除规则

- 删除只影响当前草稿，**保存后**才会进入新版本；
- 删除“使用中”的规则并保存当前版本，会影响下一次排产；
- 不确定时建议“另存为新版本”，保留旧版本可回滚。

## 8. 版本管理

### 8.1 三种状态

| 状态 | 含义 | 能不能改 |
|---|---|---|
| 使用中 | 当前生效版本，下一次排产使用它 | 可以“保存当前版本”覆盖；不能删除 |
| 草稿 | 已保存但未启用 | 可以覆盖、可以删除 |
| 历史版本 | 旧版本 | 不能覆盖；可以查看、另存、删除（至少保留一个版本） |

### 8.2 保存当前版本 vs 另存为新版本

| 操作 | 什么时候用 | 结果 | 风险 |
|---|---|---|---|
| **保存当前版本** | 草稿微调；或确认要立即修改当前生效方案 | 版本号不变，内容被覆盖 | 旧内容无法恢复；使用中版本会立即影响下一次排产 |
| **另存为新版本** | 正式调整；需要保留旧版本回滚；多人评审 | 生成 v+1，原版本保留 | 需要再点“设为当前方案”才会生效 |

**建议**：

- 日常试验、需要对比/回滚：优先 **另存为新版本**；
- 只改错别字、说明，或确认无需回滚的小调整：可以用 **保存当前版本**；
- 覆盖“使用中”版本前，页面会明确警告“历史内容无法恢复”。

### 8.3 设为当前方案

- 把选中的版本设为“使用中”，其他版本自动变为“历史版本”；
- 下一次排产立即使用新方案，不需要重启服务；
- 回滚也是这个操作：选中旧版本 → 设为当前方案。

### 8.4 删除版本

- 当前使用中的版本不能删除；
- 至少保留一个版本；
- 草稿和历史版本可以删除，删除后不可恢复；
- 入口：`更多 → 版本管理与说明 → 删除`。

### 8.5 版本说明

版本说明是给团队看的“变更摘要”，建议写“改了什么 + 为什么”：

- `v6：半成品每班至少 100 件，消除 1~2 件碎班次`
- `v7：成品允许 105%，应对月底冲量`
- `v8：客户分级权重调整，战略客户优先`

可以在顶部“版本说明”点“编辑”，也可以在“版本管理与说明”里逐个补写。

## 9. 试算此方案

### 9.1 试算是什么

用**当前草稿**（不一定已保存）跑一次标准排产，看看这版规则的结果，不会修改正在使用的方案。

### 9.2 选择试算口径

弹窗里可以选择：

| 选项 | 可选值 | 说明 |
|---|---|---|
| 计划期 | 7 / 10 / 15 / 30 天 | 看多长周期的排产结果 |
| 工作制 | 7×3 / 6×3 / 5×3 / 5×2 / 4×3 | 一周上几天、每天几班 |
| 每班工时 | 8 / 12 小时 | 单班可用工时 |

选择会记住，下次打开沿用。顶部“试算口径”标签也会同步显示。

> 试算使用系统内置标准主数据和标准起始日（当前为 10/12），与主界面当前上传的文件/日历可能不同，主要用于**横向比较规则方案**；正式结果以主界面排产为准。

### 9.3 试算指标怎么读

| 指标 | 业务含义 | 怎么看 |
|---|---|---|
| 准时交付率 | 成品订单按时完成的比例 | 越高越好；下降说明交期变紧或规则过严 |
| 生产块数 | 工单被拆成多少生产块 | 越少换型越少，但可能牺牲交付/利用率 |
| 低于 95% 的班次 | 已开班但负荷不足 95% 的数量 | 越少越好；多说明开班浪费或规则太松 |
| 半成品小于 MPQ 的班次 | 半成品班次块小于一个包装量 | 应尽量为 0；对应“1~2 件碎班次”问题 |
| 半成品非整倍班次 | 半成品班次不是 MPQ 整倍数 | 严格整箱要求下应尽量为 0 |
| 半成品最小班次批量 | 所有半成品班次里的最小件数 | 例如 100，表示最小班次也有一个包装量 |

**示例（v6，10 天 7×3）**：

- 准时交付率 85.7%
- 生产块数 59
- 低于 95% 的班次 0
- 半成品小于 MPQ 的班次 0
- 半成品非整倍班次 44
- 半成品最小班次批量 100 件

这说明“1~2 件碎班次”已经消除，但半成品班次仍不一定是严格整箱倍数；如果业务要求严格整倍，需要进一步调整 MPQ 规则和产能上限。

### 9.4 试算不可行怎么办

如果提示“当前方案排不出可行计划”，可以按顺序尝试：

1. 把某条“必须满足”改成“尽量满足”（例如交期、产能上限、连续生产块数）；
2. 放宽最高负荷 100% → 105%；
3. 延长计划期（7 → 10 → 15 → 30 天）；
4. 调整工作制（例如从 5×2 改为 6×3 或 7×3）；
5. 缩小某条规则的作用范围（只对某条线/某个料号生效）。

## 11. 典型操作场景

### 11.1 消除半成品 1~2 件碎班次

1. 打开 **03 产能与班次 → 最少投产批量（半成品）**。
2. 设置：按件、每个班次、每班最少 **100** 件、必须满足。
3. 试算 10 天 7×3，看“半成品小于 MPQ 的班次”是否为 0。
4. 满意后 **另存为新版本**，写清版本说明。
5. **设为当前方案**，回主界面重新排产。

### 11.2 允许成品 105%，半成品保持 100%

1. 打开 **03 产能与班次 → 班次负荷区间（成品）**。
2. 最高负荷改成 **105%**。
3. 确认半成品的“班次负荷区间”仍是 **100%**。
4. 试算，观察低于 95% 的班次和准时交付率。
5. 另存/保存并启用。

### 11.3 交期从“必须准时”改成“尽量准时”

1. 打开 **02 交付与客户 → 交期 / 截单**。
2. 执行方式改成 **尽量准时**。
3. 试算，观察准时交付率和生产块数。
4. 注意：改成“尽量”后允许晚交，但会扣分；如果业务仍要求硬交期，不要改。

### 11.4 战略客户优先保供

1. 打开 **02 交付与客户 → 客户分级保供**。
2. 设置战略/核心/普通的重要程度，例如 10 / 3 / 1。
3. 确认交期是“尽量准时”，否则客户分级的作用有限。
4. 试算，比较战略客户订单的完成时间。

### 11.5 只对某条线收紧规则

1. 找到要调整的规则（例如“班次负荷区间”）。
2. 点开 **高级设置 → 适用产线**，填 `PGLINKAGE`。
3. 阶段选成品或半成品，料号留空。
4. 保存后，这条规则只影响 PGLINKAGE，其他线保持原样。

### 11.6 回滚到旧版本

1. 顶部版本下拉选择旧版本（例如 v5）。
2. 确认页面状态显示“历史版本”。
3. 点 **设为当前方案**，确认。
4. 下一次排产立即使用 v5；原 v6 自动变为历史版本。

### 11.7 对比 7×3 和 5×2

1. 点 **试算此方案**。
2. 选择 `10 天 · 7×3 · 8h`，开始试算，记录结果。
3. 再打开试算，改成 `10 天 · 5×2 · 8h`，重新试算。
4. 比较准时交付率、生产块数、低于 95% 班次，判断工作制是否可行。

## 12. 常见问题

**Q1：我改了参数，为什么排产结果没变？**
依次检查：

1. 是否点了“保存当前版本”或“另存为新版本”？
2. 如果是“另存为新版本”，是否点了“设为当前方案”？
3. 当前版本状态是不是“使用中”？
4. 规则开关是否打开？
5. 是否只改了“重要程度”，但规则是“必须满足”或组内只有这一条软规则？

**Q2：为什么还有 1~2 件的半成品班次？**

- 检查“最少投产批量（半成品）”是否设置为“每班至少 100 件”；
- 如果使用“整箱（MPQ）”，还会允许一个尾块；尾块可能很小；
- 如果既要求严格整倍、又要求硬 95%，可能无解；需要允许 105% 或改成“尽量满足”。

**Q3：为什么有班次低于 95%？**

- 可能是求解降级到了“软 95%”档；
- 可能该班次是尾班，被“尾班豁免”；
- 可能是规则集把 95% 设成了“尽量满足”而不是“必须满足”；
- 先看试算/求解日志里的“排产口径”。

**Q4：版本说明在哪里改？**

- 顶部“版本说明”右侧点“编辑”；
- 或 `更多 → 版本管理与说明`，对任意版本编辑说明。

**Q5：为什么删除不了某个版本？**

- 当前“使用中”的版本不能删除；
- 至少保留一个版本；
- 先切换到其他版本，再删除旧的。

**Q6：保存当前版本和另存为新版本怎么选？**

- 需要回滚、评审、正式发布：**另存为新版本**；
- 草稿微调、确认无需回滚：**保存当前版本**；
- 覆盖“使用中”版本前，页面会警告历史无法恢复。

**Q7：试算要跑多久？**

- 一般 30~60 秒，取决于计划期和规则复杂度；
- 试算使用标准主数据，结果用于比较规则方案，不等于主界面最终排产。

**Q8：Excel 和页面是什么关系？**

- 页面是主编辑入口；Excel 适合批量编辑、评审、备份；
- Excel 导入会生成新版本；导入前建议先导出当前版本备份。

**Q9：页面在 80% 缩放下显示不全？**

- 页面按浏览器宽度自适应，建议使用 100%~80% 缩放；
- 若顶部按钮换行，属于正常自适应，不影响功能。

## 13. 术语小抄

| 术语 | 业务解释 |
|---|---|
| 使用中 | 当前生效的规则方案 |
| 草稿 | 已保存但未启用的方案 |
| 历史版本 | 旧方案，可查看、可回滚、可删除（不能覆盖） |
| 必须满足 | 做不到就不允许排出计划 |
| 尽量满足 | 做不到会扣分，但允许排出计划 |
| 重要程度 | “尽量满足”规则之间的相对重要性，不是分钟/金额 |
| 成品 / 半成品 | 总装成品 / 前道半成品（冲压、注塑等） |
| MPQ | 最小包装量/最小批量 |
| MOQ | 最小起订量 |
| 95% 负荷 | 已开班次的最低利用率 |
| 尾班豁免 | 每条线最后一个开班允许低于 95% |
| 换型 | 换模具、换型号、换线造成的停机时间 |
| 同模连产 | 同一模具的工单尽量连续生产 |
| 冻结期 | 最近若干班次锁定，避免频繁变更 |
| 替代产线 | 任务可以在认证过的其他产线生产（当前尚未接入求解） |
