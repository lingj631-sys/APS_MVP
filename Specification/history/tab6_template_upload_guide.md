# Tab-6 主数据模板下载与上传操作指引（物流测试版）

> 适用：WL（温岭）、SY38（沈阳）两个工厂的物流计划同事
> 入口：系统第 6 个 Tab →「数据源与配置维护」
> 模板第一张表「填写说明 Instructions」是唯一的填写标准：先看“表清单”，再看对应表的“字段说明”。

---

## 1. 下载模板（务必先选对站点）

1. 在页面顶部/左侧确认当前站点已经是 **WL** 或 **SY38**；
2. 点击「下载主数据填写模板 (APS_DataSource_Template.xlsx · 15 表 · 当前站点 XX)」；
3. 下载文件使用**同一套 15 表标准**，并预填当前站点的数据：
   - WL：17 成品 / 22 半成品 / 65 条订单 / 3 条产线；
   - SY38：11 成品 / 5 半成品 / 16 条订单 / 3 条产线（PU07、PU22、1400T-6，12h×2 班）。

> 模板由系统按当前站点实时生成，并禁用了浏览器缓存；不同站点下载到的不是同一份 WL 文件。

---

## 2. 填写规则（不要做的事）

- **不要改第 1 行表头文字**；列顺序可以调整，但不能删列/改列名；
- **不要删除工作表**；15 张表必须保留（说明页也在内）；
- **站点列必须与当前工厂一致**（WL 或 SY38）；否则上传会被拒绝；
- 空白行可以保留，系统会跳过；
- 旧版灰色列已从模板删除，不要再补回；上传旧文件时残留这些列也不影响读取；
- 生产日期轴请勿删整列；新增日期向右侧追加即可。

---

## 3. 上传与生效

1. 确认页面站点仍是目标工厂；
2. 点击「上传 Excel 数据源」，选择填好的 `.xlsx`；
3. 成功后会提示，例如：
   `已载入 xx.xlsx（新版 15 表：成品 17 / 半成品 22 / 订单 65，数据提示 0 条）`；
4. 系统会立即：
   - 校验 15 张表与必需列；
   - 解析并重建该站点的净需求/BOM/库存/日历；
   - 把文件保存为 `data/uploads/current_<站点>.xlsx`；
   - 刷新 `/api/inputs` 与 `/api/solve` 使用的快照；
5. 回到排产页执行「智能排产」。

> WL 与 SY38 的上传文件互相独立，不会覆盖对方。

---

## 4. 常见拒绝原因

| 提示 | 处理 |
|---|---|
| 缺少必要工作表 | 不要删除 15 张表中的任何一张 |
| 表头缺少列 | 恢复第 1 行原始列名（列顺序可变） |
| 上传文件中没有 XX 工厂的成品/半成品参数数据 | 检查「站点」列是否全部是当前工厂 |
| 只接受 .xlsx / 文件为空 / 超过 25MB | 另存为 xlsx、检查文件 |

---

## 5. 测试建议

1. 先下载 WL 模板 → 原样上传 → 应看到 17/22/65 与 0 条提示；
2. 再切换 SY38 → 下载 SY38 模板 → 原样上传 → 应看到 11/5/16，产线为 3 条 12h×2；
3. 修改某一条需求数量（例如 +100）→ 上传 → 运行 5/10 天排产，确认任务量变化；
4. 若上传后出现「数据提示」，先在「数据源与配置维护」卡片查看前 3 条，再决定是否继续排产。
